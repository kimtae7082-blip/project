JavaScript DOM 객체

DOM(Document Object Model) 객체는 HTML 문서를 객체로 표현한 모델입니다. DOM을 통해 JavaScript에서 HTML 요소를 조작할 수 있습니다.

DOM(Document Object Model) 객체

DOM은 HTML 문서를 객체로 표현한 모델입니다. DOM을 통해 JavaScript에서 HTML 요소를 조작할 수 있습니다.

DOM 객체 예제

아래는 DOM 사용하여 HTML 요소를 조작하는 예제입니다.

  • document.title: 문서의 제목
  • document.URL: 문서의 URL
  • document.body: 문서의 body 요소
  • document.head: 문서의 head 요소
  • document.getElementById('myButton'): id가 'myButton'인 요소
  • document.getElementsByClassName('myClass'): class가 'myClass'인 요소들
  • document.getElementsByTagName('button'): button 태그 요소들
  • document.querySelector('#myButton'): CSS 선택자 '#myButton'에 해당하는 첫 번째 요소
  • document.querySelectorAll('.myClass'): CSS 선택자 '.myClass'에 해당하는 모든 요소들

DOM 객체를 사용하여 HTML 요소를 조작할 수 있습니다.
